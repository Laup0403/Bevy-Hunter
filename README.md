# Bevy Hunter
a top down shooter, that can load thousands of birds<br>
<img width="1920" height="1080" alt="titelbild" src="https://github.com/user-attachments/assets/176fb6fc-4134-4bd3-a523-9bddc313dc4a" />
Bevy Hunter is a shooter made in [Bevy](https://bevy.org/) by Laupi_oida<br>
It was made to test the capabilities of bevy.<br>
- Without Birds: 400 - 500 Fps<br>
- With 100k Birds: 40 - 80 Fps<br>
## Controls
WASD -> Movement<br>
EQ -> Zoom<br>
Left Mouse Button -> Single shot<br>
Right Mouse Button -> Rapid fire<br>
Scroll Wheel -> Adjust max birds<br>
Tab -> Menu<br>

## Install Instructions
Download the game from [releases](https://github.com/Laup0403/Bevy-Hunter/releases/tag/release) and extract it<br>
or<br>
1. Download the source code
2. built it with `cargo build --release`
3. add everything from `assets/` to `target/release/assets/`
4. run the file `target/release/bevy-hunter` or `target/release/bevy-hunter.exe`
